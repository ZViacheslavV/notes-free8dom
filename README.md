📝 [NoteHubFree8dom (web application)]([https://09-auth-rho-six.vercel.app](https://notes-free8dom.vercel.app))

> Modern application for creating, organizing, and browsing personal notes.

NoteHub focuses on clean architecture, reliable data flow, and a smooth user experience built on top of a robust TypeScript + Next.js foundation.

---

## 🛠️ Tech Stack

- **TypeScript** — static safety, predictable logic

- **Next.js** / React — components, routing, SSR/CSR, advanced patterns

- **REST API** — structured data exchange

- **Vite** — fast local development

- **Git** — version control
